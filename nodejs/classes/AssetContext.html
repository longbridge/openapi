    bankCards

    • bankCards(): Promise<BankCard[]>

      Get the linked bank cards, with their verification, binding and authorization (eDDA, bank securities account, FPS) status

      AP accounts only: US data-center accounts get a region error.

      Example

      const { OAuth, Config, AssetContext } = require('longbridge')

      const oauth = await OAuth.build('your-client-id', (_, url) => console.log('Visit:', url));
      const ctx = AssetContext.new(Config.fromOAuth(oauth));
      const resp = await ctx.bankCards();
      console.log(resp);

      Returns Promise<BankCard[]>

    eddaApplications

    • eddaApplications(cardId: string, currency: string): Promise<EddaApplication[]>

      Get the eDDA authorization applications of a bank card in one currency

      cardId is BankCard.id; currency is e.g. HKD or USD. The card id must be all digits; any other value fails with an error before anything is sent.

      AP accounts only: US data-center accounts get a region error.

      Example

      const oauth = await OAuth.build('your-client-id', (_, url) => console.log('Visit:', url));
      const ctx = AssetContext.new(Config.fromOAuth(oauth));
      const resp = await ctx.eddaApplications('12345', 'HKD');
      console.log(resp);

    couponOrders

    • couponOrders(cardId: string, orderType: CouponOrderType): Promise<CouponOrder[]>

      Get the orders a coupon was applied to

      cardId is Coupon.cardId (32 hex characters, not a bank card ID); any other value fails with an error before anything is sent. The gateway rate-limits this route tightly per member, so avoid calling it concurrently.

      AP accounts only: US data-center accounts get a region error.

      Example

      const { OAuth, Config, AssetContext } = require('longbridge')

      const oauth = await OAuth.build('your-client-id', (_, url) => console.log('Visit:', url));
      const ctx = AssetContext.new(Config.fromOAuth(oauth));
      const resp = await ctx.couponOrders(couponId, CouponOrderType.Settled);
      console.log(resp);

      Parameters

      • cardId: string
      • orderType: CouponOrderType

      Returns Promise<CouponOrder[]>

    deposits

    • deposits(opts?: GetDepositsOptions | null): Promise<DepositsResponse>

      Get one page of deposit records

      The server's total follows the page size rather than the record count, so it is not returned; hasMore reports a full page instead. The page size is always sent: at most 20, default 20.

      AP accounts only: US data-center accounts get a region error.

      Example

      const { OAuth, Config, AssetContext } = require('longbridge')

      const oauth = await OAuth.build('your-client-id', (_, url) => console.log('Visit:', url));
      const ctx = AssetContext.new(Config.fromOAuth(oauth));
      const resp = await ctx.deposits({ size: 20 });
      console.log(resp.items, resp.hasMore);

      Parameters

      • Optionalopts: GetDepositsOptions | null

      Returns Promise<DepositsResponse>
