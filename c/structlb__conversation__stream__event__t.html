Detailed Description

One event observed while streaming lb_agent_context_conversation_streamed or lb_agent_context_continue_conversation_streamed.

This is a tagged union: kind tells you which one field below is non-null; all others are always null. When kind is Ping (a heartbeat with no payload), every field below is null.
